## 快速开始

<Steps>
  <Step title="获取 API Key">
    登录 DreamTo 控制台，在 **API Key** 页面创建 API Key。
  </Step>
  <Step title="创建视频生成任务">
    ```bash
    curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
      -H "Authorization: Bearer $DREAMTO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "seedance-2.0",
        "content": [
          { "type": "text", "text": "一只橘猫在阳光下的窗台上伸懒腰，慢镜头" }
        ],
        "ratio": "16:9",
        "duration": 5,
        "resolution": "720p"
      }'
    ```
    创建成功返回任务 ID：`{"id": "task_...", "request_id": "req_..."}`。
  </Step>
  <Step title="查询任务结果">
    ```bash
    curl "https://api.dreamto.ai/api/v3/contents/generations/tasks/task_xxx" \
      -H "Authorization: Bearer $DREAMTO_API_KEY"
    ```
    `status` 为 `succeeded` 时，从 `content.video_url` 下载视频；也可以在创建任务时传 `callback_url`，由平台主动推送结果。更多用法见 [场景示例](/video/seedance-2-0/scenarios/text-to-video)。
  </Step>
</Steps>

## 通用约定

- 请求与响应均为 JSON，编码 UTF-8。
- 视频任务接口字段全程使用 snake_case；素材库接口为 Action 风格，字段使用 PascalCase。
- 每个响应都带 `X-Request-Id` 响应头，视频任务接口的响应体顶层同时带 `request_id`。排查问题时请提供该值与任务 `id`。
- 时间戳字段（`created_at` / `updated_at`）为 Unix 秒；素材库时间字段为 UTC ISO 8601 字符串。
- 文档右上角可切换中文 / English；API 参考页的参数说明与 OpenAPI 定义由 Gateway 源码自动生成。
