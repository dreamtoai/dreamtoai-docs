每张图片的 `role` 传 `reference_image`（最多 9 张），按出现顺序编号为「图片1」「图片2」…，在提示词中用 `[图片N]` 指明各自的用途。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance-2-5/create-task)，在请求示例下拉框中选择「多图参考生视频」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

  -H "Authorization: Bearer $DREAMTO_API_KEY" \

  -d '{
    "model": "seedance-2.5",

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance-2-5/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance-2-5/create-task)。
