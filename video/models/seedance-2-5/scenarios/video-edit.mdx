在 `content` 中带 `role: reference_video` 的参考视频（mp4 / mov，2 ~ 15 秒；Seedance 2.5 最多 10 个，2.0 最多 3 个），提示词描述要修改的内容。`seedance-2.0` 按素材自行判定生成方式，无需传 `omni_reference_task_type`；用 `seedance-2.5` 时建议传 `omni_reference_task_type: edit` 明确为编辑。Fast / Mini 不支持视频编辑。`ratio` / `duration` 按你传入的值生效。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance-2-5/create-task)，在请求示例下拉框中选择「视频编辑」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "将视频1中的房子外立面墙壁刷成蓝色，天气改为雪天"
      },
      {
        "type": "video_url",
        "video_url": {
          "url": "https://example.com/house.mp4"
        },
        "role": "reference_video"
      }
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "将视频1中的房子外立面墙壁刷成蓝色，天气改为雪天"
        },
        {
            "type": "video_url",
            "video_url": {
                "url": "https://example.com/house.mp4"
            },
            "role": "reference_video"
        }
    ],
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance-2-5/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance-2-5/create-task)。
