接口路径、请求体、响应体和错误结构与 [MiniMax 官方 V2 视频接口](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create) 一致。已经接入官方的代码，只需要改两处：

| | MiniMax 官方 | DreamTo |
|---|---|---|
| 服务地址 | `https://api.minimaxi.com` | `https://api.dreamto.ai` |
| API Key | MiniMax 平台密钥 | DreamTo 控制台的 API Key |

## 接口

| 接口 | 用途 |
|---|---|
| [`POST /v2/video_generation`](/api-reference/minimax-h3/create-video-generation) | 创建视频生成任务 |
| [`POST /v2/video_regeneration`](/api-reference/minimax-h3/create-video-regeneration) | 创建视频再生成任务 |
| [`POST /v2/h3_context_ir`](/api-reference/minimax-h3/create-context-ir) | 创建 H3 Context IR 任务 |
| [`GET /v2/query/video_generation/{task_id}`](/api-reference/minimax-h3/query-task) | 查询任务 |

## 参数范围

超出范围返回 400，不建任务、不扣费。

| 字段 | 取值 |
|---|---|
| `model` | `MiniMax-H3` |
| `resolution` | `768P` / `2K`（再生成固定 `2K`） |
| `duration` | `4` ~ `15` 秒的整数 |
| `ratio` | `adaptive` / `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`；文生视频必填且不能为 `adaptive` |
| 图片 | 首帧 ≤ 1、尾帧 ≤ 1、参考图 ≤ 9 |
| 视频 / 音频 | 各 ≤ 3 个，每段 2 ~ 15 秒，总时长 ≤ 15 秒 |
| 素材地址 | 公网 `http(s)` 地址或 Base64；请求体 ≤ 64 MB |

## 计费

按 MiniMax 官方价格计费，以控制台显示的模型价格为准。失败、取消的任务和参数错误不扣费。

| 计费项 | 价格 |
|---|---|
| 输出视频 768P | $0.08 / 秒 |
| 输出视频 2K | $0.13 / 秒 |
| 参考视频输入 | 与所选分辨率的输出价格相同，按输入秒数 |
| 输入图片 | 每个任务前 5 张免费，之后 $0.04 / 张 |
| 参考音频 | 免费 |
| 视频再生成（768P → 2K） | 输出 $0.05 / 秒，参考视频输入 $0.05 / 秒，超出 5 张的图片 $0.025 / 张 |
| H3 Context IR | 输入 $0.90 / 百万 Token，输出 $3.60 / 百万 Token |

## 快速开始

创建任务拿到 `task_id`，每 10 ~ 30 秒查询一次，`status` 为 `succeeded` 时从 `content.url` 下载视频。

```python Python
import os
import time

import requests

BASE_URL = "https://api.dreamto.ai"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "MiniMax-H3",
    "content": [
        {
            "type": "text",
            "text": "史诗级太空歌剧预告：女舰长独自站在巨大的观景窗前，最后一支舰队集结后跃迁离去，强光爆闪，舰桥震动。"
        }
    ],
    "resolution": "2K",
    "duration": 5,
    "ratio": "16:9"
}

task_id = requests.post(f"{BASE_URL}/v2/video_generation", headers=HEADERS, json=payload, timeout=60).json()["task_id"]
while True:
    task = requests.get(f"{BASE_URL}/v2/query/video_generation/{task_id}", headers=HEADERS, timeout=60).json()["task"]
    if task["status"] in ("succeeded", "failed", "cancelled"):
        break
    time.sleep(15)
print(task["status"], task.get("content", {}).get("url"), task.get("error"))
```

## 与官方接口的差异

- 只提供 `MiniMax-H3`；`MiniMax-H3-Highspeed`、`MiniMax-H3-Lite`、`MiniMax-H3-Max` 及 Max 专用的 `extra` 参数暂不支持。
- 暂不支持 `callback_url`，请轮询查询任务接口。
- 素材地址不支持 `mm_file://`（MiniMax 文件存储的文件 Id），请使用公网地址或 Base64。
- 暂不提供任务列表、取消和删除接口。
- `task_id` 与错误响应中的 `request_id` 由 DreamTo 生成；`content.url` 为 DreamTo 下载地址（`/v2/files/...`），最长 7 天有效，请及时下载保存。
