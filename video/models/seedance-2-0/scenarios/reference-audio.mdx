音频的 `role` 为 `reference_audio`（wav / mp3，2 ~ 15 秒，最多 3 个），在提示词中用「音频1」引用。可与参考图片组合使用。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance-2-0/create-task)，在请求示例下拉框中选择「参考音频」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      {
        "type": "text",
        "text": "[图片1]中的舞者在霓虹街头起舞，动作与音频1的鼓点同步，快速剪辑"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/dancer.png"
        },
        "role": "reference_image"
      },
      {
        "type": "audio_url",
        "audio_url": {
          "url": "https://example.com/beat.mp3"
        },
        "role": "reference_audio"
      }
    ],
    "ratio": "9:16",
    "duration": 8,
    "resolution": "720p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0",
    "content": [
        {
            "type": "text",
            "text": "[图片1]中的舞者在霓虹街头起舞，动作与音频1的鼓点同步，快速剪辑"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/dancer.png"
            },
            "role": "reference_image"
        },
        {
            "type": "audio_url",
            "audio_url": {
                "url": "https://example.com/beat.mp3"
            },
            "role": "reference_audio"
        }
    ],
    "ratio": "9:16",
    "duration": 8,
    "resolution": "720p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance-2-0/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance-2-0/create-task)。
