`duration: -1` 由模型自选时长（Seedance 2.5 为 4 ~ 30 秒，其余模型 4 ~ 15 秒）并按实际用量计费；`callback_url` 在任务结束后接收 POST 回调；`return_last_frame: true` 返回尾帧，可作为下一段的首帧；固定 `seed` 便于复现。回调之外仍建议保留低频轮询兜底。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance-2-0/create-task)，在请求示例下拉框中选择「智能时长 + 回调通知」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      {
        "type": "text",
        "text": "海浪拍打礁石，镜头从远景缓慢推进到浪花特写，日落时分"
      }
    ],
    "ratio": "16:9",
    "duration": -1,
    "resolution": "1080p",
    "seed": 20261111,
    "return_last_frame": true,
    "bitrate_mode": "high",
    "callback_url": "https://your-server.example.com/dreamto/callback"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0",
    "content": [
        {
            "type": "text",
            "text": "海浪拍打礁石，镜头从远景缓慢推进到浪花特写，日落时分"
        }
    ],
    "ratio": "16:9",
    "duration": -1,
    "resolution": "1080p",
    "seed": 20261111,
    "return_last_frame": True,
    "bitrate_mode": "high",
    "callback_url": "https://your-server.example.com/dreamto/callback"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance-2-0/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance-2-0/create-task)。
