- ⏱️ **长视频**：`duration` 4 ~ 30 秒，不传时默认智能时长（`-1`）
- 🖼️ **更多参考素材**：图片最多 30 张、视频与音频各最多 10 个
- 🎛️ **任务类型可控**：`omni_reference_task_type` 可选 `auto` / `reference` / `edit` / `extend`
- 🎬 **480p / 720p / 1080p** 三档输出

**Base URL**: `https://api.dreamto.ai`　·　**model**: `seedance-2.5`

<Info>
  接口、鉴权、任务查询与回调和其他 Seedance 模型完全相同，只需把 `model` 换成 `seedance-2.5`。通用说明见 [Seedance 通用说明](/video/seedance-2-0)。
</Info>

## 参数范围

以下取值由平台按本模型校验，超出范围返回 HTTP 400，不会创建任务、不会扣费。

| 字段 | 默认值 | 本模型取值 |
|---|---|---|
| `model` | — | `seedance-2.5` |
| `duration` | `-1`（智能时长） | `4` ~ `30` 秒的整数，或 `-1` 智能时长 |
| `resolution` | `720p` | `480p` / `720p` / `1080p` |
| `ratio` | `adaptive` | `adaptive` / `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` |
| `frames` | 不传 | 正整数，与 `duration` 二选一，`frames` 优先 |
| `generate_audio` | `true` | `true` / `false` |
| `real_person_mode` | `true` | `true` / `false` |
| `omni_reference_task_type` | 不传（按素材判定） | `auto` / `reference` / `edit` / `extend` |

其余参数（`seed`、`watermark`、`return_last_frame`、`bitrate_mode`、`tools`、`callback_url` 等）见 [API 全部参数](/api-reference/seedance/create-task)。

## 参考素材

| 类型 | 本模型上限 | 用途 |
|---|---|---|
| 图片 `image_url` | 30 张 | 首帧 / 尾帧 / 参考图 |
| 视频 `video_url` | 10 个 | 参考视频（视频编辑 / 延长） |
| 音频 `audio_url` | 10 个 | 参考音频 |

素材上限由模型执行，超限时任务以 `failed` 终态返回原因。素材地址须为公网 `http` / `https` 地址，或素材库的 `asset://<素材Id>`。

视频编辑 / 延长：**支持**。

## 快速开始

创建任务后轮询结果，`status` 为 `succeeded` 时下载 `content.video_url`。示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
# 1. 创建任务
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "清晨的海边小镇，镜头从高空缓缓下降，穿过街道来到一家面包店门口，店主推门微笑"
      }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
  }'

# 2. 查询任务（替换为上一步返回的 id）
curl "https://api.dreamto.ai/api/v3/contents/generations/tasks/task_8c1d2e3f4a5b6c7d8e9f0a1b" \
  -H "Authorization: Bearer $DREAMTO_API_KEY"
```

```python Python
import os
import time

import requests

URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "清晨的海边小镇，镜头从高空缓缓下降，穿过街道来到一家面包店门口，店主推门微笑"
        }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(URL, headers=HEADERS, json=payload, timeout=60)
resp.raise_for_status()
task_id = resp.json()["id"]

while True:
    task = requests.get(f"{URL}/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "succeeded":
        print(task["content"]["video_url"])
        break
    if task["status"] == "failed":
        raise RuntimeError(task["error"]["message"])
    time.sleep(5)
```

```javascript Node.js
const URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks";
const headers = {
  Authorization: `Bearer ${process.env.DREAMTO_API_KEY}`,
  "Content-Type": "application/json",
};

const payload = {
  "model": "seedance-2.5",
  "content": [
    {
      "type": "text",
      "text": "清晨的海边小镇，镜头从高空缓缓下降，穿过街道来到一家面包店门口，店主推门微笑"
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p"
};

const created = await fetch(URL, { method: "POST", headers, body: JSON.stringify(payload) });
if (!created.ok) throw new Error(JSON.stringify(await created.json()));
const { id } = await created.json();

for (;;) {
  const task = await (await fetch(`${URL}/${id}`, { headers })).json();
  if (task.status === "succeeded") {
    console.log(task.content.video_url);
    break;
  }
  if (task.status === "failed") throw new Error(task.error.message);
  await new Promise((r) => setTimeout(r, 5000));
}
```

## 本模型常见报错

| 场景 | HTTP | 返回 |
|---|---|---|
| `duration` 超出 4 ~ 30 或不是整数 | 400 | `duration 仅支持 4~30 秒或 -1(智能时长)` |
| `resolution` 不在 `480p` / `720p` / `1080p` 中 | 400 | `resolution 仅支持 480p / 720p / 1080p` |
| 账号未开放该模型 | 404 | `error.code` 为 `not_found` |

400 的 `error.message` 为平台原文（中文）。全部错误码见 [错误码](/errors)。
