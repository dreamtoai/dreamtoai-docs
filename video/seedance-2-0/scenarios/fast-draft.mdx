`seedance-2.0-fast` 与 `seedance-2.0-mini` 是轻量版本，适合批量试提示词或出草稿（价格以控制台模型价格为准）；只支持 `480p` / `720p`，传 `1080p` 返回 400。确定效果后可把 `model` 换成 `seedance-2.0` 或 `seedance-2.5` 出成片，其余参数不变。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance/create-task)，在请求示例下拉框中选择「Fast / Mini 快速出片」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-fast",
    "content": [
      {
        "type": "text",
        "text": "一杯冰咖啡放在木桌上，冰块缓缓融化，阳光透过窗户"
      }
    ],
    "ratio": "9:16",
    "duration": 5,
    "resolution": "480p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0-fast",
    "content": [
        {
            "type": "text",
            "text": "一杯冰咖啡放在木桌上，冰块缓缓融化，阳光透过窗户"
        }
    ],
    "ratio": "9:16",
    "duration": 5,
    "resolution": "480p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

```javascript Node.js
const payload = {
  "model": "seedance-2.0-fast",
  "content": [
    {
      "type": "text",

  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.DREAMTO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify(payload),
});
console.log(resp.status, await resp.json()); // { id: 'task_...', request_id: 'req_...' }
```

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance/create-task)。
