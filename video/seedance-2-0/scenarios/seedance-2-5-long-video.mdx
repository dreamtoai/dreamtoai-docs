只有 `seedance-2.5` 支持 16 ~ 30 秒的 `duration`，其余模型最长 15 秒，超出返回 400。Seedance 2.5 还可携带更多参考素材（图片最多 30 张、视频与音频各最多 10 个），并通过 `omni_reference_task_type` 指定参考 / 编辑 / 延长。时长越长，生成耗时与费用越高。

<Tip>
  想直接调试？打开 [创建视频生成任务](/api-reference/seedance/create-task)，在请求示例下拉框中选择「Seedance 2.5 长视频」，填入 API Key 后点击 **Try it**。
</Tip>

## 请求示例

示例中的 `$DREAMTO_API_KEY` 为你的 API Key。

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "图片1中的旅行者清晨从山脚出发，穿过森林、溪流，最终登上山顶看日出，镜头一路跟随"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/traveler.jpg"
        },
        "role": "reference_image"
      }
    ],
    "ratio": "16:9",
    "duration": 20,
    "resolution": "1080p",
    "omni_reference_task_type": "reference"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "图片1中的旅行者清晨从山脚出发，穿过森林、溪流，最终登上山顶看日出，镜头一路跟随"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/traveler.jpg"
            },
            "role": "reference_image"
        }
    ],
    "ratio": "16:9",
    "duration": 20,
    "resolution": "1080p",
    "omni_reference_task_type": "reference"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## 响应

创建成功返回 HTTP 200。`request_id` 与响应头 `X-Request-Id` 相同，排查问题时请提供：

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

拿到任务 `id` 后，调用 [查询任务](/api-reference/seedance/get-task) 轮询结果，`status` 为 `succeeded` 时读取 `content.video_url`。全部请求参数与取值说明见 [创建视频生成任务](/api-reference/seedance/create-task)。
