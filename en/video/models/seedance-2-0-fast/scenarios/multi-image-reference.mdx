Give each image `role: reference_image` (up to 9). They are numbered in order as image 1, image 2…; say in the prompt what each one is for, e.g. `[image 1]`.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance-2-0-fast/create-task), pick "Multi-image reference" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-fast",
    "content": [
      {
        "type": "text",
        "text": "The boy with glasses in a blue T-shirt from [image 1] and the corgi from [image 2] sit on the lawn from [image 3], cartoon style"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/boy.png"
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance-2-0-fast/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance-2-0-fast/create-task) for every parameter and value.
