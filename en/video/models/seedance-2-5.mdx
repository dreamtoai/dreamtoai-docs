## Parameters

Out-of-range values return 400; no task is created and nothing is billed.

| Field | Default | Allowed for this model |
|---|---|---|
| `model` | — | `seedance-2.5` |
| `duration` | `-1` (smart duration) | Integer `4`–`30` seconds, or `-1` for smart duration |
| `resolution` | `720p` | `480p` / `720p` / `1080p` |
| `ratio` | `adaptive` | `adaptive` / `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` |
| `generate_audio` | `true` | `true` / `false` |
| `real_person_mode` | `true` | `true` / `false` |
| `omni_reference_task_type` | omitted (derived) | `auto` / `reference` / `edit` / `extend` |

All parameters: [Create video task](/en/api-reference/seedance-2-5/create-task).

## Reference media

| Type | Limit for this model | Purpose |
|---|---|---|
| Image `image_url` | 30 | First frame / last frame / reference |
| Video `video_url` | 10 | Reference video (edit / extend) |
| Audio `audio_url` | 10 | Reference audio |

Media must be public `http(s)` URLs or `asset://<asset Id>`; exceeding a limit fails the task.

## Quick start

Create a task and poll it; when `status` is `succeeded`, read `content.video_url`.

```python Python
import os
import time

import requests

URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "A seaside town at dawn; the camera descends from above, glides down the street to a bakery, and the owner opens the door with a smile"
        }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(URL, headers=HEADERS, json=payload, timeout=60)
resp.raise_for_status()
task_id = resp.json()["id"]

while True:
    task = requests.get(f"{URL}/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "succeeded":
        print(task["content"]["video_url"])
        break
    if task["status"] == "failed":
        raise RuntimeError(task["error"]["message"])
    time.sleep(5)
```

```javascript Node.js
const URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks";
const headers = {
  Authorization: `Bearer ${process.env.DREAMTO_API_KEY}`,
  "Content-Type": "application/json",
};

const payload = {
  "model": "seedance-2.5",
  "content": [
    {
      "type": "text",
      "text": "A seaside town at dawn; the camera descends from above, glides down the street to a bakery, and the owner opens the door with a smile"
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p"
};

const created = await fetch(URL, { method: "POST", headers, body: JSON.stringify(payload) });
if (!created.ok) throw new Error(JSON.stringify(await created.json()));
const { id } = await created.json();

for (;;) {
  const task = await (await fetch(`${URL}/${id}`, { headers })).json();
  if (task.status === "succeeded") {
    console.log(task.content.video_url);
    break;
  }
  if (task.status === "failed") throw new Error(task.error.message);
  await new Promise((r) => setTimeout(r, 5000));
}
```

## Common errors

| Case | HTTP | Returns |
|---|---|---|
| `duration` outside 4–30 or not an integer | 400 | `duration must be an integer from 4 to 30 seconds, or -1 (smart duration)` |
| `resolution` not in `480p` / `720p` / `1080p` | 400 | `resolution must be one of: 480p, 720p, 1080p` |
| Model not enabled for your account | 404 | `error.code` is `not_found` |

All codes: [Errors](/en/errors).
