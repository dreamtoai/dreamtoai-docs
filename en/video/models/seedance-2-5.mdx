- ⏱️ **Long videos**: `duration` 4–30 s, smart duration (`-1`) by default
- 🖼️ **More reference media**: up to 30 images and 10 videos / 10 audios
- 🎛️ **Explicit task type**: `omni_reference_task_type` = `auto` / `reference` / `edit` / `extend`
- 🎬 **480p / 720p / 1080p** output

**Base URL**: `https://api.dreamto.ai`　·　**model**: `seedance-2.5`

<Info>
  The endpoint, authentication, task query and callbacks are the same for every Seedance model; just set `model` to `seedance-2.5`. See the [Seedance shared guide](/en/video/seedance-2-0) for the shared details.

## Parameters

The platform validates these values for this model; out-of-range values return HTTP 400, no task is created and nothing is billed.

| Field | Default | Allowed for this model |
|---|---|---|
| `model` | — | `seedance-2.5` |
| `duration` | `-1` (smart duration) | Integer `4`–`30` seconds, or `-1` for smart duration |
| `resolution` | `720p` | `480p` / `720p` / `1080p` |
| `ratio` | `adaptive` | `adaptive` / `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` |
| `frames` | omitted | Positive integer; alternative to `duration`, `frames` wins |
| `generate_audio` | `true` | `true` / `false` |
| `real_person_mode` | `true` | `true` / `false` |
| `omni_reference_task_type` | omitted (derived) | `auto` / `reference` / `edit` / `extend` |

Other parameters (`seed`, `watermark`, `return_last_frame`, `bitrate_mode`, `tools`, `callback_url` and more) are described in [All parameters](/en/api-reference/seedance-2-5/create-task).

## Reference media

| Type | Limit for this model | Purpose |
|---|---|---|
| Image `image_url` | 30 | First frame / last frame / reference |
| Video `video_url` | 10 | Reference video (edit / extend) |
| Audio `audio_url` | 10 | Reference audio |

Limits are enforced by the model; exceeding them makes the task end as `failed` with the reason. Media URLs must be public `http` / `https` URLs or asset-library references `asset://<asset Id>`.

Video editing / extension: **Yes**.

## Quick start

Create a task, poll it, and download `content.video_url` when `status` is `succeeded`. `$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
# 1. Create the task
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "A seaside town at dawn; the camera descends from above, glides down the street to a bakery, and the owner opens the door with a smile"
      }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
  }'

# 2. Get the task (use the id returned above)
curl "https://api.dreamto.ai/api/v3/contents/generations/tasks/task_8c1d2e3f4a5b6c7d8e9f0a1b" \
  -H "Authorization: Bearer $DREAMTO_API_KEY"
```

```python Python
import os
import time

import requests

URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "A seaside town at dawn; the camera descends from above, glides down the street to a bakery, and the owner opens the door with a smile"
        }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(URL, headers=HEADERS, json=payload, timeout=60)
resp.raise_for_status()
task_id = resp.json()["id"]

while True:
    task = requests.get(f"{URL}/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "succeeded":
        print(task["content"]["video_url"])
        break
    if task["status"] == "failed":
        raise RuntimeError(task["error"]["message"])
    time.sleep(5)
```

```javascript Node.js
const URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks";
const headers = {
  Authorization: `Bearer ${process.env.DREAMTO_API_KEY}`,
  "Content-Type": "application/json",
};

const payload = {
  "model": "seedance-2.5",
  "content": [
    {
      "type": "text",
      "text": "A seaside town at dawn; the camera descends from above, glides down the street to a bakery, and the owner opens the door with a smile"
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p"
};

const created = await fetch(URL, { method: "POST", headers, body: JSON.stringify(payload) });
if (!created.ok) throw new Error(JSON.stringify(await created.json()));
const { id } = await created.json();

for (;;) {
  const task = await (await fetch(`${URL}/${id}`, { headers })).json();
  if (task.status === "succeeded") {
    console.log(task.content.video_url);
    break;
  }
  if (task.status === "failed") throw new Error(task.error.message);
  await new Promise((r) => setTimeout(r, 5000));
}
```

## Common errors for this model

| Case | HTTP | Returns |
|---|---|---|
| `duration` outside 4–30 or not an integer | 400 | `duration 仅支持 4~30 秒或 -1(智能时长)` |
| `resolution` not in `480p` / `720p` / `1080p` | 400 | `resolution 仅支持 480p / 720p / 1080p` |
| Model not enabled for your account | 404 | `error.code` is `not_found` |

For 400 errors `error.message` is the platform's original (Chinese) text. See [Errors](/en/errors) for all codes.
