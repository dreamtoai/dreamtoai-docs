## Parameters

Out-of-range values return 400; no task is created and nothing is billed.

| Field | Default | Allowed for this model |
|---|---|---|
| `model` | — | `seedance-2.0-mini` |
| `duration` | `5` | Integer `4`–`15` seconds, or `-1` for smart duration |
| `resolution` | `720p` | `480p` / `720p` |
| `ratio` | `adaptive` | `adaptive` / `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` |
| `frames` | omitted | Positive integer; alternative to `duration`, `frames` wins |
| `generate_audio` | `true` | `true` / `false` |
| `real_person_mode` | `false` | `true` / `false` |
| `omni_reference_task_type` | — | Not used by this model; valid values are ignored |

All parameters: [Create video task](/en/api-reference/seedance-2-0-mini/create-task).

## Reference media

| Type | Limit for this model | Purpose |
|---|---|---|
| Image `image_url` | 9 | First frame / last frame / reference |
| Video `video_url` | 3 | Reference video (no edit / extend) |
| Audio `audio_url` | 3 | Reference audio |

Media must be public `http(s)` URLs or `asset://<asset Id>`; exceeding a limit fails the task.

## Quick start

Create a task and poll it; when `status` is `succeeded`, read `content.video_url`.

<CodeGroup>

```bash cURL
# 1. Create the task
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-mini",
    "content": [
      {
        "type": "text",
        "text": "An orange cat lounges on a sunny windowsill, tail gently swaying"
      }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
  }'

# 2. Get the task (use the id returned above)
curl "https://api.dreamto.ai/api/v3/contents/generations/tasks/task_8c1d2e3f4a5b6c7d8e9f0a1b" \
  -H "Authorization: Bearer $DREAMTO_API_KEY"
```

```python Python
import os
import time

import requests

URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "seedance-2.0-mini",
    "content": [
        {
            "type": "text",
            "text": "An orange cat lounges on a sunny windowsill, tail gently swaying"
        }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(URL, headers=HEADERS, json=payload, timeout=60)
resp.raise_for_status()
task_id = resp.json()["id"]

while True:
    task = requests.get(f"{URL}/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "succeeded":
        print(task["content"]["video_url"])
        break
    if task["status"] == "failed":
        raise RuntimeError(task["error"]["message"])
    time.sleep(5)
```

```javascript Node.js
const URL = "https://api.dreamto.ai/api/v3/contents/generations/tasks";
const headers = {
  Authorization: `Bearer ${process.env.DREAMTO_API_KEY}`,
  "Content-Type": "application/json",
};

const payload = {
  "model": "seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "An orange cat lounges on a sunny windowsill, tail gently swaying"
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p"
};

const created = await fetch(URL, { method: "POST", headers, body: JSON.stringify(payload) });
if (!created.ok) throw new Error(JSON.stringify(await created.json()));
const { id } = await created.json();

for (;;) {
  const task = await (await fetch(`${URL}/${id}`, { headers })).json();
  if (task.status === "succeeded") {
    console.log(task.content.video_url);
    break;
  }
  if (task.status === "failed") throw new Error(task.error.message);
  await new Promise((r) => setTimeout(r, 5000));
}
```
