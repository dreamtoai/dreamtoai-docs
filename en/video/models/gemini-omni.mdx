Paths, request bodies and responses follow the [official Google Interactions API](https://ai.google.dev/api/interactions-api); the model is `gemini-omni-1.2-flash`. To migrate code written for Google, change the base URL and use a DreamTo API Key:

| | Google | DreamTo |
|---|---|---|
| Base URL | `https://generativelanguage.googleapis.com` | `https://api.dreamto.ai` |
| API Key | Google AI Studio key | API Key from the DreamTo console, in the `x-goog-api-key` or `Authorization: Bearer` header |

## Endpoints

| Endpoint | Purpose |
|---|---|
| [`POST /v1beta/interactions`](/en/api-reference/gemini-omni/create-interaction) | Generate a video |
| [`GET /v1beta/interactions/{id}`](/en/api-reference/gemini-omni/get-interaction) | Get an interaction |

## How it works

1. Call the create endpoint. The request is synchronous and returns when the video is ready, usually in 20 seconds to 2 minutes; set the client timeout to at least 10 minutes.
2. With `delivery: inline`, the Base64 video is in `steps[].content[].data` of the create response.
3. With `delivery: uri`, query the returned `id` and download the video from `steps[].content[].uri`. The link needs no API Key and is valid for 24 hours, so download and store videos promptly.

<Note>
  The create response always has `status: in_progress`; with `delivery: uri` its `uri` cannot be downloaded directly, so use the link returned by the query endpoint. The query endpoint only returns interactions created by the same API Key within 24 hours.
</Note>

## Parameters

Undeclared parameters and the parameters listed as not supported below return 400; the model is not called and nothing is charged.

| Field | Values |
|---|---|
| `model` | `gemini-omni-1.2-flash` |
| `response_format.aspect_ratio` | `16:9` (default) / `9:16` |
| `response_format.resolution` | `360p` / `720p` (default) / `1080p` / `4k` |
| `response_format.duration` | `3s`–`15s`, default `10s`; `3s`–`10s` for first/last frame and extend; edits keep the input duration |
| `response_format.delivery` | `uri` / `inline`; `inline` when omitted |
| Images | Public `https` link in `uri`, or Base64 in `data`; up to 6 reference images |
| Videos | Base64 in `data` only (video links are not supported); videos to edit ≤ 15 s |
| Audio | Audio input is not supported yet |

## Pricing

Billed by token usage at the model price shown in the console; higher resolutions and longer videos use more tokens. Invalid requests and failed generations are not charged.

## Quick start

<CodeGroup>

```bash cURL
# 1. Generate (synchronous; waits until done)
curl -X POST "https://api.dreamto.ai/v1beta/interactions" \
  --max-time 900 \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-omni-1.2-flash",
    "input": "A futuristic city at night, slow dolly-in, neon reflections on the wet street.",
    "response_format": {
      "type": "video",
      "aspect_ratio": "16:9",
      "resolution": "720p",
      "duration": "8s",
      "delivery": "uri"
    }
  }'

# 2. Query the interaction and read steps[].content[].uri
curl "https://api.dreamto.ai/v1beta/interactions/job_2805f00afeeb52775470220f" \
  -H "Authorization: Bearer $DREAMTO_API_KEY"
```

```python Python
import os

import requests

BASE_URL = "https://api.dreamto.ai"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "gemini-omni-1.2-flash",
    "input": "A futuristic city at night, slow dolly-in, neon reflections on the wet street.",
    "response_format": {
        "type": "video",
        "aspect_ratio": "16:9",
        "resolution": "720p",
        "duration": "8s",
        "delivery": "uri"
    }
}

created = requests.post(f"{BASE_URL}/v1beta/interactions", headers=HEADERS, json=payload, timeout=900).json()
interaction = requests.get(f"{BASE_URL}/v1beta/interactions/{created['id']}", headers=HEADERS, timeout=60).json()
video = next(c for s in interaction["steps"] if s["type"] == "model_output" for c in s["content"])
with open("output.mp4", "wb") as f:
    f.write(requests.get(video["uri"], timeout=300).content)
```

</CodeGroup>

## Differences from Google

- Only `gemini-omni-1.2-flash` is available.
- Asynchronous (`background`), streaming (`stream`) and follow-up turns (`previous_interaction_id`) are not supported yet; use synchronous requests and send the video in `input` to edit it.
- Interaction `id`s are issued by DreamTo (prefixed `job_`); video links are DreamTo links (`/v1beta/files/...`).
- Errors use the DreamTo error envelope (see the error examples of each endpoint) with English messages.
