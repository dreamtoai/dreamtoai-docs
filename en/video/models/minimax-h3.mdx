Paths, request bodies, responses and errors match the [official MiniMax V2 video API](https://platform.minimax.io/docs/api-reference/video-generation-v2-create). Code written for MiniMax needs two changes:

| | MiniMax | DreamTo |
|---|---|---|
| Base URL | `https://api.minimax.io` | `https://api.dreamto.ai` |
| API Key | MiniMax platform key | API Key from the DreamTo console |

## Endpoints

| Endpoint | Purpose |
|---|---|
| [`POST /v2/video_generation`](/en/api-reference/minimax-h3/create-video-generation) | Create video generation task |
| [`POST /v2/video_regeneration`](/en/api-reference/minimax-h3/create-video-regeneration) | Create video regeneration task |
| [`POST /v2/h3_context_ir`](/en/api-reference/minimax-h3/create-context-ir) | Create H3 Context IR task |
| [`GET /v2/query/video_generation/{task_id}`](/en/api-reference/minimax-h3/query-task) | Query task |

## Parameters

Values out of range return 400; no task is created or charged.

| Field | Values |
|---|---|
| `model` | `MiniMax-H3` |
| `resolution` | `768P` / `2K` (`2K` for regeneration) |
| `duration` | Integer from `4` to `15` seconds |
| `ratio` | `adaptive` / `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`; required and not `adaptive` for text-to-video |
| Images | First frame ≤ 1, last frame ≤ 1, reference images ≤ 9 |
| Video / audio | Up to 3 each, 2–15 s per clip, 15 s in total |
| Media | Public `http(s)` URL or Base64; request body ≤ 64 MB |

## Pricing

Billed at the official MiniMax prices; the model price in the console is authoritative. Failed or cancelled tasks and invalid requests are not charged.

| Item | Price |
|---|---|
| Output video 768P | $0.08 / second |
| Output video 2K | $0.13 / second |
| Reference video input | Same as the output price of the chosen resolution, per input second |
| Input images | First 5 per task free, then $0.04 / image |
| Reference audio | Free |
| Regeneration (768P → 2K) | Output $0.05 / second, reference video $0.05 / second, images beyond 5 $0.025 / image |
| H3 Context IR | Input $0.90 / M tokens, output $3.60 / M tokens |

## Quick start

Create a task to get a `task_id`, poll every 10–30 seconds, and download `content.url` once `status` is `succeeded`.

<CodeGroup>

```bash cURL
# 1. Create the task
curl -X POST "https://api.dreamto.ai/v2/video_generation" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "Epic space-opera teaser: a captain stands alone at a vast observation window as the last fleet jumps away in a blinding flash, the bridge shaking."
      }
    ],
    "resolution": "2K",
    "duration": 5,
    "ratio": "16:9"
  }'

# 2. Query the task
curl "https://api.dreamto.ai/v2/query/video_generation/794576931165300894" \
  -H "Authorization: Bearer $DREAMTO_API_KEY"
```

```python Python
import os
import time

import requests

BASE_URL = "https://api.dreamto.ai"
HEADERS = {"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"}

payload = {
    "model": "MiniMax-H3",
    "content": [
        {
            "type": "text",
            "text": "Epic space-opera teaser: a captain stands alone at a vast observation window as the last fleet jumps away in a blinding flash, the bridge shaking."
        }
    ],
    "resolution": "2K",
    "duration": 5,
    "ratio": "16:9"
}

task_id = requests.post(f"{BASE_URL}/v2/video_generation", headers=HEADERS, json=payload, timeout=60).json()["task_id"]
while True:
    task = requests.get(f"{BASE_URL}/v2/query/video_generation/{task_id}", headers=HEADERS, timeout=60).json()["task"]
    if task["status"] in ("succeeded", "failed", "cancelled"):
        break
    time.sleep(15)
print(task["status"], task.get("content", {}).get("url"), task.get("error"))
```

## Differences from MiniMax

- Only `MiniMax-H3` is available; `MiniMax-H3-Highspeed`, `MiniMax-H3-Lite`, `MiniMax-H3-Max` and the Max-only `extra` parameter are not supported yet.
- `callback_url` is not supported yet; poll the query endpoint.
- `mm_file://` media (MiniMax file storage IDs) is not supported; use public URLs or Base64.
- Task list, cancel and delete endpoints are not provided.
- `task_id` and the `request_id` of error responses are issued by DreamTo; `content.url` is a DreamTo download link (`/v2/files/...`) valid for at most 7 days, so download and store videos promptly.
