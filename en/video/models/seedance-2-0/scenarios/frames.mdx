`frames` and `duration` are alternatives; `frames` wins when both are present and usage is billed as generated. Useful when you must match an editing timeline exactly.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance-2-0/create-task), pick "Exact frame count" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      {
        "type": "text",
        "text": "An orange cat stretches on a sunny windowsill, slow motion"
      }
    ],
    "ratio": "16:9",
    "frames": 121,
    "resolution": "720p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0",
    "content": [
        {
            "type": "text",
            "text": "An orange cat stretches on a sunny windowsill, slow motion"
        }
    ],
    "ratio": "16:9",
    "frames": 121,
    "resolution": "720p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance-2-0/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance-2-0/create-task) for every parameter and value.
