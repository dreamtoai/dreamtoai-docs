`duration: -1` lets the model choose the length (4–30 s on Seedance 2.5, 4–15 s on the other models) and bills actual usage; `callback_url` receives a POST when the task ends; `return_last_frame: true` returns the last frame to seed the next clip; a fixed `seed` helps reproduction. Keep low-frequency polling as a fallback to the callback.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance-2-5/create-task), pick "Smart duration + callback" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "Waves crash on the rocks at sunset; the camera slowly moves from a wide shot to a close-up of the spray"
      }
    ],
    "ratio": "16:9",
    "duration": -1,
    "resolution": "1080p",
    "seed": 20261111,
    "return_last_frame": true,
    "bitrate_mode": "high",
    "callback_url": "https://your-server.example.com/dreamto/callback"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "Waves crash on the rocks at sunset; the camera slowly moves from a wide shot to a close-up of the spray"
        }
    ],
    "ratio": "16:9",
    "duration": -1,
    "resolution": "1080p",
    "seed": 20261111,
    "return_last_frame": True,
    "bitrate_mode": "high",
    "callback_url": "https://your-server.example.com/dreamto/callback"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance-2-5/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance-2-5/create-task) for every parameter and value.
