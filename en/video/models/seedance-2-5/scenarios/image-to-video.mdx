Set the image `role` to `first_frame`; the video starts from it. With a first frame the output follows the image ratio and `ratio` has no effect. Describe how the image should move; no need to restate what it shows.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance-2-5/create-task), pick "Image to video (first frame)" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "Slow push-in, the person smiles, hair gently moving in the breeze, cinematic lighting"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/portrait.jpg"
        },
        "role": "first_frame"
      }
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "Slow push-in, the person smiles, hair gently moving in the breeze, cinematic lighting"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/portrait.jpg"
            },
            "role": "first_frame"
        }
    ],
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance-2-5/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance-2-5/create-task) for every parameter and value.
