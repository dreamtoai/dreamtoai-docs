Add a reference video with `role: reference_video` (mp4 / mov, 2–15 s; up to 10 on Seedance 2.5, 3 on 2.0) and describe the change in the prompt. `seedance-2.0` derives the mode from the material, so `omni_reference_task_type` is not needed; with `seedance-2.5`, send `omni_reference_task_type: edit` to make it explicit. Fast / Mini do not support video editing. `ratio` / `duration` are honored as given.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance/create-task), pick "Video editing" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      {
        "type": "text",
        "text": "Paint the exterior walls of the house in video 1 blue and change the weather to snow"
      },
      {
        "type": "video_url",
        "video_url": {
          "url": "https://example.com/house.mp4"
        },
        "role": "reference_video"
      }
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0",
    "content": [
        {
            "type": "text",
            "text": "Paint the exterior walls of the house in video 1 blue and change the weather to snow"
        },
        {
            "type": "video_url",
            "video_url": {
                "url": "https://example.com/house.mp4"
            },
            "role": "reference_video"
        }
    ],
    "duration": 5,
    "resolution": "720p"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance/create-task) for every parameter and value.
