Pass `tools: [{"type": "web_search"}]` to enable web search, useful for news, trends or recent facts. `web_search` is the only tool.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance/create-task), pick "Web search" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "content": [
      {
        "type": "text",
        "text": "Make a short video introducing the most popular travel destination right now"
      }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "tools": [
      {
        "type": "web_search"
      }
    ]
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.0",
    "content": [
        {
            "type": "text",
            "text": "Make a short video introducing the most popular travel destination right now"
        }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "tools": [
        {
            "type": "web_search"
        }
    ]
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance/create-task) for every parameter and value.
