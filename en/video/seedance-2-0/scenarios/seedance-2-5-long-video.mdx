Only `seedance-2.5` accepts a `duration` of 16–30 seconds; the other models stop at 15 and return 400 beyond that. Seedance 2.5 also takes more reference media (up to 30 images and 10 videos / 10 audios) and lets you choose reference / edit / extend with `omni_reference_task_type`. Longer videos take longer and cost more.

<Tip>
  Want to try it? Open [Create video task](/en/api-reference/seedance/create-task), pick "Seedance 2.5 long video" in the request example dropdown, enter your API Key and click **Try it**.
</Tip>

## Request

`$DREAMTO_API_KEY` is your API Key.

<CodeGroup>

```bash cURL
curl -X POST "https://api.dreamto.ai/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $DREAMTO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "The traveler in image 1 sets off from the foot of the mountain at dawn, passes through a forest and a stream, and reaches the summit at sunrise; the camera follows all the way"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/traveler.jpg"
        },
        "role": "reference_image"
      }
    ],
    "ratio": "16:9",
    "duration": 20,
    "resolution": "1080p",
    "omni_reference_task_type": "reference"
  }'
```

```python Python
import os
import requests

payload = {
    "model": "seedance-2.5",
    "content": [
        {
            "type": "text",
            "text": "The traveler in image 1 sets off from the foot of the mountain at dawn, passes through a forest and a stream, and reaches the summit at sunrise; the camera follows all the way"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/traveler.jpg"
            },
            "role": "reference_image"
        }
    ],
    "ratio": "16:9",
    "duration": 20,
    "resolution": "1080p",
    "omni_reference_task_type": "reference"
}

resp = requests.post(
    "https://api.dreamto.ai/api/v3/contents/generations/tasks",
    headers={"Authorization": f"Bearer {os.environ['DREAMTO_API_KEY']}"},
    json=payload,
    timeout=60,
)
print(resp.status_code, resp.json())  # {'id': 'task_...', 'request_id': 'req_...'}
```

## Response

On success the API returns HTTP 200. `request_id` equals the `X-Request-Id` header; include it when contacting support:

```json
{
  "id": "task_8c1d2e3f4a5b6c7d8e9f0a1b",
  "request_id": "req_3f9a1c2b7d4e5f60718293a4"
}
```

With the task `id`, poll [Get task](/en/api-reference/seedance/get-task); when `status` is `succeeded`, read `content.video_url`. See [Create video task](/en/api-reference/seedance/create-task) for every parameter and value.
